# Mi primer repositorio

Práctica de Git y GitHub con un programa sencillo en C++.

## Descripción

El programa muestra el mensaje "Hola, GitHub!" en la terminal.

## Archivos

- `hola.cpp`: código fuente del programa.
- `.gitignore`: excluye los ejecutables de Windows.
- `README.md`: presentación e instrucciones del proyecto.

## Requisitos

- Un compilador de C++ compatible con g++.
- Una terminal para compilar y ejecutar el programa.

## Cómo compilar y ejecutar

Desde la carpeta del proyecto, compilar con:

```powershell
g++ hola.cpp -o hola.exe
```

Ejecutar en PowerShell con:

```powershell
.\hola.exe
```

### Resultado esperado

```text
Hola, GitHub!
```
